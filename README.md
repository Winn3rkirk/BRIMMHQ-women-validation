# BRIMMHQ women-first validation prototype

This repository contains a low-fidelity participant prototype for testing two BRIMMHQ concepts: requesting support between healthcare visits and receiving simple check-in messages.

## Validation use only

- This is not a production healthcare service.
- It does not provide clinical advice or emergency care.
- It has no backend, authentication, database, APIs, analytics, or participant data storage.
- The voice-note option is intentionally inactive and never requests microphone access.
- All interaction state exists only in memory and resets when the page refreshes.
- Participants should use imaginary or harmless examples.

## Run locally

Open `index.html` in a browser, or serve the directory with any simple static server.

## Deployment

The site is designed for GitHub Pages from the `main` branch and repository root. No paid services are required.

## Scope

This repository intentionally excludes moderator scripts, observation notes, participant records, and research synthesis. Those materials must remain private and separate from the public site.
